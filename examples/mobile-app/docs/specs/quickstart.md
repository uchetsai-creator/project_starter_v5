# Quickstart

## Prerequisites

- Flutter SDK 3.22 or higher
- Xcode 15+ (for iOS builds) or Android Studio with an Android 12+ emulator

## Setup

1. Clone the repository: `git clone https://github.com/example/habitly.git`
2. Install dependencies: `flutter pub get`
3. Generate local database bindings: `dart run build_runner build`
4. Launch on a connected device or emulator: `flutter run`

## Verification

Run `flutter test` to confirm the unit and widget test suite passes, then confirm the
app launches to the Onboarding screen on a clean install.
